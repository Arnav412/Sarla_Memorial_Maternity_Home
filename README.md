# Sarla Memorial Maternity Home Website

This is the repository for the official website I developed for **Sarla Memorial Maternity Home** (established under the aegis of Sarla Memorial Charitable Trust in loving memory of Smt. Sarla Gupta). 

The website is fully responsive, optimized for performance, and serves as an informational portal and appointment booking system for patients.

🌐 **Live Link**: [https://sarla-memorial-maternity-home-1.onrender.com/](https://sarla-memorial-maternity-home-1.onrender.com/)

---

## 🌟 Key Features

- **Motto & Identity**: Highlights the transparent circular hospital badge logo, mission motto (*"We Care, God Cures"*), state registration details, and charitable trust history.
- **Specialized Procedures**: Sections showcasing Obstetric care, Gynecological procedures, and Preventative Screenings.
- **Core Visiting Panel**: Professional listings for our core specialists (Dr. R R Gupta, Dr. Shanti Swaroop Sharma, Dr. Manoj Kumar Mahajan, and Dr. Rajnesh Kumar).
- **Interactive Oncology Camp Program**: Dynamic 6-card flipping deck detailing oncologists and timings for the monthly cancer OPD clinic (First Saturday of each month).
- **ENT Specialist Profile**: A clean profile card for Dr. Rajeev Sharma showing weekly timings (Tuesday & Friday) and local language consultations.
- **Secure Email Notifications**: Integrated booking form connecting to **FormSubmit.co**, routing patient appointment requests directly to my email at `sarlamemorialmaternityhome99@gmail.com`.
- **Floating Contact Panel**: A floating selector widget at the bottom-left of the screen with click-to-call links and instant phone number copying.

## 🚀 Running Locally

To run this website locally on your computer, start a simple HTTP server in the project directory:

```bash
# Start a simple Python web server
python3 -m http.server 8000
```

Once running, navigate to **[http://localhost:8000](http://localhost:8000)** in your web browser.

## ✉️ Appointment Form Setup (FormSubmit)

The appointment booking form is connected to my email. To activate notifications for the first time:
1. Go to the live website and submit a test appointment request.
2. Open the inbox of **`sarlamemorialmaternityhome99@gmail.com`**.
3. Open the activation email sent by **FormSubmit** and click the verification button.
4. All future booking submissions will route directly to the inbox.
